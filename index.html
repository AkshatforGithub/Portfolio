CASE STUDY / 01

AI-Powered
Trending Topic Bot

A fully autonomous n8n workflow that posts a trend-aware tweet every day with zero manual input.

n8nNewsAPI / GNewsGoogle TrendsGroqX APIOAuth 1.0a
DAILYscheduled automation

THE SYSTEM

From live signals to a published post.

The workflow pulls live trending signals from NewsAPI/GNews and Google Trends in parallel, normalizes both feeds with custom JavaScript transforms, and merges them into one candidate pool.

An AI Agent powered by Groq evaluates the merged candidates and selects the strongest topic rather than simply taking the first result. Rolling-week memory tracks topic history so recurring topics can strengthen as a trend signal instead of being automatically discarded.

A second LLM step drafts the final tweet. The completed post is then published to X through the X API using OAuth 1.0a, removing the need for a human login step.

OUTPUTTweet published to X

CASE STUDY / 02

DocuMind
Ask your documents.

A retrieval-augmented assistant that reads a company's documents once and answers questions about them in plain language, the way you'd ask a colleague.

n8nGoogle DrivePineconeGemini EmbeddingsGroqSlack
SELF-HEALINGfailures alert Slack automatically

THE SYSTEM

From documents to instant answers.

Whenever a file is added or updated in the company's document folder, DocuMind notices automatically, extracts the text and splits it into smaller chunks. Each chunk is converted into an embedding — a numerical fingerprint of its meaning — and stored in a Pinecone vector database, so answers can be found by meaning rather than exact wording.

When a question comes in, the workflow searches that memory for the most relevant chunks and hands them, along with the original question, to an AI agent running on Groq. The agent writes a natural-language answer grounded in the actual documents rather than a guess, and sends it back the same way the question arrived.

If a document is re-uploaded, DocuMind clears out the old vectors for that file before adding the new version, so its memory never ends up carrying duplicate or outdated information.

INPUTCompany documents
DECISIONVector search + AI agent
OUTPUTAnswer delivered in chat
RELIABILITYAuto-alerts on failure

01 / THE AUTOMATION

REAL-WORLD RELIABILITY

Built to never fail silently.

A dedicated error-handling workflow runs alongside DocuMind at all times. The moment a step fails — a file that won't download, an AI provider that's briefly unavailable — it captures exactly what broke and posts a plain-language alert to Slack, often before anyone using the assistant even notices.

IMPACT

One accurate answer, straight from the source.

Team members and customers get answers grounded in the actual company documents instead of searching through PDFs manually, and the assistant's knowledge updates automatically the moment a document changes.
